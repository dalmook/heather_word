# Heather Word 12 — 탐험 경험과 제품화

기준: main `3dd92a17b65a9e758d49fe09f7f96c48151032af` (2026-09-05).

## 변경 전 분석

구조: 빌드 없는 GitHub Pages main/root. app.js 학습/보상/관리 엔진,
season2-core.js 적응형 학습과 성장 계산, season2.js 모험, ui-v9.js 표시/라우팅,
ui/ 공통 디자인. Firebase 동기화와 기기 저장을 함께 제공한다.

기존 전체 기능 목록은 FEATURE_REGRESSION_CHECKLIST.md의 F01–F40과 같다.
카드, 4게임, 21문제 모험, 복습, 점수/쿠키/XP, 두 도감, 펫, 아바타,
상점, 일일/주간 보상, PIN, 관리자 권한, 단어 관리, 백업/복원, 리포트를 보존한다.

흐름: 진입 → 홈 → 카드/게임/모험 → 피드백 → 다음/완료 → 성장·복습.
부모 흐름: PIN → 단어 관리 또는 학습 리포트 → 다음 학습 결정.

문제: 신규 기기의 words.json은 비어 있어 제품을 경험하기 전에 단어 준비가 필요하다.
홈은 기능 카드가 나열되고 작은 SVG 위주라 제품 고유의 인상이 약하다.
학습 기록은 있으나 최근 7일의 습관과 다음 행동을 함께 판단하기 어렵다.
실제 결제 서비스, 구매 권한 검증, 가족 계정은 없으므로 결제 가능하다고 표시할 수 없다.

## 실행 범위

1. 원화 탐험 장면과 일관된 숲 색상, 명확한 첫 행동, 실제 진도와 파트너.
2. 명시적으로 시작하는 무료 체험: 직접 작성한 6개 주제·60개 기초 영어 단어.
   별도 저장 키와 LOCAL 모드로 기존 사용자 및 Firebase 데이터와 분리.
3. PIN 보호 부모 대시보드: 실제 답변 기록, 최근 7일, 숙련, 복습, 인쇄.
4. 보호자 안내: 현재 제공 범위와 준비 중인 가족 멤버십을 구분.
   결제·구독·연락처 수집·추적 SDK·가짜 후기·가짜 할인은 추가하지 않는다.
5. 기존 학습 알고리즘과 저장 스키마를 유지하고 필요한 초기화 상수만 확장.

## 수익화 경계

전환 구조는 무료 체험 → 학습 습관/성장 확인 → 보호자 가치 설명이다.
후속 유료 상품은 가족 계정, 기기 간 자녀별 동기화, 주제별 학습팩,
장기 리포트 중심으로 제안한다. 가격은 운영자가 확정하기 전 사용자에게 약속하지 않는다.
실제 판매 개시는 PG 계정/서버 결제 검증/구매 권한/환불 및 운영정책 준비 후 진행한다.
현 버전에서는 실결제와 유료 권한을 활성화하지 않는다.
