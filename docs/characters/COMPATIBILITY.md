# 변경 범위와 보존 계약

기준: main 9d295e2d8375ebbf246c25d2964999f6497f3b90. 별도 브랜치에서만 작업한다. 사용자/운영 Firebase 기록에 테스트용 재화나 캐릭터를 쓰지 않는다.

## 저장과 경제

스키마를 변경하지 않는다. 12개 세계, 20종, 60개 시즌2 ID, 원래 1,000 XP 도감, 56개 아바타와 18개 이전 소품, 5개 Pet ID를 유지한다. 표시 이름 60개는 ID를 유지한 채 `name-map.json`으로 추적한다. 가격·확률·경험치·진화 재료·조건을 바꾸지 않는다. 최신 시즌2 revision 보호, Firebase 연결/규칙, LOCAL/체험 저장 키와 부모 접근 보호는 그대로 둔다.

홈 프로필과 드레스룸의 보이는 모습은 새 공통 렌더러를 사용한다. 소유하지 않은 코디는 기존 draft에만 들어가며 보유 또는 실제 장착으로 저장하지 않는다. PNG는 현재 미리보기를 내보내는 이미지이며 구매 권한을 부여하지 않는다. 전체 의상 우선순위를 새 슬롯 없이 해결한다. 기존 Pet의 레벨/먹이/성장/돌봄 함수는 수정하지 않는다.

획득일은 기존 activityLog의 최초 starter/hatch(중복 제외)/evolve 기록만 사용한다. 과거 기록이 없거나 잘못되었으면 기록 없음으로 표시한다. 출시일이나 현재 시각을 소급 입력하지 않는다.

진화/부화 저장 후 연출을 실행한다. 연출에는 데이터 쓰기/보상 지급 코드가 없다. 건너뛰기·닫기·탭 이동·새로고침은 이미 저장된 결과를 지우거나 다시 지급하지 않는다.

## 기존 테스트의 의도된 변경

기존 commercial/kids 검사 중 렌더러 파일 전체 해시는 작화를 바꾸면 반드시 달라진다. 원래 fixture는 수정하지 않았다. monster-catalog-season2.js와 avatar-phaser.js의 전체 파일 동일성 대신 정확한 카탈로그/가격/ID/슬롯 계약, 런타임-정적 파일 일치, 공통 렌더러/폴백/자원 정리, 실제 브라우저 검증을 적용한다. core/rules/words의 원래 바이트 동일성 검사는 유지한다.

app.js는 작화와 목록 페이지네이션에 해당하는 12개 함수만 옛 해시를 명시적으로 대입해 나머지 함수 전체의 원래 집계 해시가 동일한지 계속 검사한다. 예외 목록과 원본 커밋은 `tests/fixtures/character-visual-functions.json`에 고정한다. 시험을 통과시키기 위해 원래 집계 해시를 다시 만들지 않았다. 구입/장착/정규화/보상 함수는 여전히 원본 해시 대상이다.

season2.js의 그림 표시 함수와 성공한 저장 뒤 연출을 부르는 래퍼만 변경한다. 그 밖의 기존 조정 함수 전체를 기준 커밋의 개별 해시로 보호한다. 가장 마지막 escapeAttr은 새 함수 사이의 공백 차이만 있으므로 본문까지 별도로 고정한다. 순수 core의 데이터 왕복, 진화/보상 재처리, 기존 세이브 보존을 추가한다. 실제 1,000개를 렌더링하되 동시에 DOM에 넣는 수는 60개로 제한하고 마지막 번호까지 페이지로 접근하게 한다.

## 환경과 남은 검증 경계

단위 검사와 벡터 검사는 로컬 Node에서 실행하고, 실제 페이지 검사는 GitHub Actions의 Chrome에서 실행한다. 390px/320px 캡처는 에뮬레이션 뷰포트이며 실제 Android/iOS 기기 시험이 아니다. 운영 Firebase 쓰기와 실제 매출·아동 대상 사용성 조사는 하지 않는다. 세부 실행 결과는 QA 보고서와 CI artifact에 구분해 기록한다.
