# Heather Word — 작은 탐험 수첩의 친구들

버전 13.0.0 · 대상 7–10세 어린이와 가족 · 기준 코드 9d295e2d8375ebbf246c25d2964999f6497f3b90

## 디자인의 중심

캐릭터는 단어를 배워 함께 여행하는 친구다. 손으로 만든 스티커 같은 또렷한 외곽선, 따뜻한 종이색의 작은 하이라이트, 몸의 기능을 설명하는 소품을 사용한다. 갑옷의 양이나 후광보다 얼굴과 실루엣이 먼저 읽힌다. 실제 상업적 반응이나 상품 생산 적합성이 입증되었다는 뜻은 아니다.

기존 유명 IP는 완성도와 애착의 참고 기준일 뿐이다. 그 캐릭터나 스타일을 제작 원본으로 사용하지 않았다. 모든 배포 벡터는 이 저장소의 직접 작성한 경로와 파츠 정의에서 생성한다. 외부 캐릭터 에셋·스톡 캐릭터·폰트를 포함하지 않는다. 서비스 출시 전 별도의 이름·유사성 검토는 여전히 필요하다.

## 공통 작화 규칙

몬스터는 240×240 좌표계, 바닥 약 216, 그림자 약 218을 사용한다. 몸 그림은 안전 여백 확보를 위해 (6,7)에서 .95배 배치한다. 아바타는 240×320, 머리 중심 (120,100), 목 (120,144), 손 (64,222)/(177,223), 발 약 281을 사용한다. 표시 크기 64/128/256에서 비교한다. 작은 크기에선 눈·귀·꼬리와 큰 소품, 큰 크기에서 이음선과 광택을 읽는다.

외곽선은 대체로 2.6–3.4, 둥근 끝/이음, 주색보다 어두운 계열색이다. 주색·크림색 보조·한 가지 역할 강조색을 중심으로 한다. 광원은 왼쪽 위, 그림자는 바닥에만 얕게 둔다. 무거운 필터와 반짝임으로 부족한 캐릭터 구조를 숨기지 않는다. 모든 캐릭터의 정체성은 배경 없이 유지되어야 한다.

눈은 밝은 반사점이 있는 눈, 행복할 때 짧은 곡선 눈으로 구분한다. 오답은 울거나 화난 표정 대신 다정한 재도전 문구로 전달한다. 대기 호흡·깜빡임은 홈/상세/학습 파트너 같은 주목 대상만 실행한다. 목록은 정적이다. 사용자 모션 줄이기·비활성 탭·화면 밖 상태를 존중한다.

잠금 상태는 실제 파츠의 외곽을 같은 단색으로 채운다. 내부 표정·무늬·소품 세부선·그림자를 제거한다. 잠긴 캐릭터의 실제 이름을 접근성 제목에서 노출하지 않는다.

## 진화 설계

첫 만남은 종의 특징이 보이는 작은 친구다. 두 번째 모습은 동행의 역할이 생긴다. 마지막은 그 역할이 완성된다. 20종 모두 별도 그림 함수를 가지며 3단계별 경로·비율·파츠를 다르게 정의한다. 같은 그림에 왕관만 얹는 공통 진화 템플릿은 사용하지 않는다. 대표 검토 대상으로 포실곰 계열, 톱니봇 계열, 불씨용 계열을 사용한다. 각 종별 이름·모티프·변화는 `inventory.json`과 `name-map.json`에 연결된다.

전설은 책장으로 만든 넓은 어깨, 혜성 목털, 화산 막날개, 갈라지는 별뿔처럼 정지 상태에서 고유 구조가 읽혀야 한다. 목록에서 무거운 파티클을 상시 실행하지 않는다. 등급 표시는 기존 common/rare/hero/legend 값을 유지하며 도형 배지·문구도 함께 쓴다.

## 아바타와 꾸미기

전체 의상은 상의/하의보다 우선한다. 별도 상의/하의를 미리 보면 전체 의상을 제외한다. 뒤 액세서리 → 뒷머리 → 몸 → 하의/신발 → 옷 → 손 → 얼굴 → 앞머리 → 앞 액세서리 순서를 사용한다. 안경은 눈 좌표에, 지팡이는 오른손, 날개와 케이프는 몸 뒤에 둔다. UI의 소품 하위 분류를 별도 저장 슬롯으로 늘리지 않는다. 10개 슬롯과 56개 ID/가격/소유권은 그대로다.

`character-avatar.js`가 홈·프로필·상점 미리보기·드레스룸·PNG의 유일한 작화 기준이다. Phaser는 별도 도형을 그리지 않고 같은 SVG를 텍스처로 표시한다. 실패 시 DOM 그림과 PNG 저장을 사용할 수 있다. 피부색/헤어/의상 조합은 데이터에 있는 값을 유지한다. 희귀 아이템만 예쁘게 만드는 대신 기본 착장도 동일한 얼굴/봉제선 마감을 가진다.

## 원본과 배포

`character-art.js`, `character-avatar.js`, `character-companions.js`는 편집 가능한 제작 원본이자 실행 중 렌더러다. `npm run generate:assets`는 60개 시즌2, 기존 40개 레이어, 56개 아이템 미리보기, 5개 펫, 18개 소품, 20개 XP 계열 대표 파일을 만든다. 생성기를 다시 실행해도 옛 그림으로 돌아가지 않는다. 런타임은 카탈로그에 현재 필요한 캐릭터만 SVG로 삽입한다. 배포 파일 199개를 처음부터 다운로드하지 않는다.

별도 1,000종은 기존 XP 번호/이름/조건 그대로이며 20개 계열과 기존 단계에 따른 배색/소품 생성형이다. 1,000개를 개별 수작업으로 디자인했다고 주장하지 않는다. 스티커로 보기 좋은 구성은 목표이나 CMYK 분판·칼선·봉제 패턴·실물 생산 샘플은 이번 산출물이 아니다.
