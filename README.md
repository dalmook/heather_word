# Heather Word v6.0 · Firebase 버전

초등학교 1학년용 영어 단어/스펠링 학습 앱입니다.

## 이번 버전의 방향

- `index.html`, `style.css`, `app.js`, `words.json`으로 분리
- 스캔/OCR 제거
- 한 화면 앱 구조
- 정답 시 자동 다음 문제 이동
- 키보드가 올라와도 입력창이 보이도록 `visualViewport` 대응
- Firebase 설정에 따라 LOCAL 또는 동기화 모드로 실행
- Firebase 설정을 넣으면 여러 기기에서 단어/카테고리 공유
- 익명 로그인 기반 사용자별 점수/랭킹 지원

## 파일 구조

```text
heather_word/
├─ index.html
├─ style.css
├─ app.js
├─ words.json
├─ firebase-config.js
├─ firebase.json
├─ firestore.rules
└─ README.md
```

## Firebase 연결 방법

1. Firebase Console에서 프로젝트 생성
2. Authentication > Sign-in method > Anonymous 사용 설정
3. Firestore Database 생성
4. `firestore.rules` 내용을 Firestore Rules에 붙여넣고 Publish
5. Project settings > Your apps > Web app 생성
6. 받은 설정값을 `firebase-config.js`에 입력
7. `window.HEATHER_USE_FIREBASE = true;` 로 변경

Firebase가 설정된 배포에서도 주소 뒤에 `?mode=local`을 붙이면 동기화 없이 현재 기기에서만 사용할 수 있습니다. 운영 데이터에 영향을 주지 않는 점검에도 활용할 수 있습니다.

## 게임 점수표

| 모드 | 기본 점수 | 학습 의도 |
| --- | ---: | --- |
| 뜻 | +1 | 빠른 확인용이며 점수 비중은 최소화 |
| 블록 | +15 | 철자 배열 연습 |
| 빈칸 | +40 | 일부 힌트가 있는 철자 회상 |
| 쓰기 | +100 | 전체 철자 직접 회상 |

- 카드 화면의 `알아요`는 단어별 최초 1회에 한해 +1점이며, 게임 콤보 보너스에는 포함되지 않습니다.
- 3연속 정답 보너스는 각 모드 기본 점수의 20% 수준으로 적용되어 어려운 모드의 보상이 유지됩니다.
- 한 문제를 연속 클릭하거나 Enter 키를 반복해도 채점은 한 번만 이루어집니다.
- 틀리거나 `몰라요`를 누르면 정답 확인 화면이 유지되며, 사용자가 `다음 문제`를 눌러야 넘어갑니다.
- 모드는 자유롭게 선택하며, 한 번 시작하면 `뜻 10개`, `블록 10개`, `빈칸 10개`, `쓰기 10개`까지만 출제됩니다.
- 모드별 완주 보너스는 뜻 +10, 블록 +100, 빈칸 +200, 쓰기 +500점까지 정답 수에 비례해 지급됩니다.

## 몬스터 도감과 관리 잠금

- 몬스터는 총 1000종입니다. 기존 1~100번의 해금 기준은 유지되어 이미 획득한 몬스터가 다시 잠기지 않습니다.
- 새 희귀 몬스터인 101번부터는 다음 해금 간격이 1,500 XP로 시작하고, 20종마다 500 XP씩 더 커집니다.
- 도감은 현재 저장된 XP를 기준으로 계산되므로 기존에 모아 둔 점수도 바로 획득 기록에 반영됩니다.
- 관리 화면 진입 시 비밀번호 `3341`을 입력해야 하며, 잠금 해제는 현재 브라우저 탭 동안 유지됩니다.
- 이 비밀번호는 화면 편집을 막는 간단한 잠금입니다. 공개 배포에서 진짜 관리자 권한을 보호하려면 Firestore 보안 규칙과 인증 권한을 별도로 구성해야 합니다.

## 데이터 저장 원칙

- 같은 영어 단어라도 서로 다른 카테고리에는 각각 독립적으로 저장됩니다.
- 같은 카테고리에서 같은 단어를 다시 저장하면 기존 항목을 수정합니다.
- 일괄 추가의 중복 판정도 선택한 카테고리 안에서만 수행합니다.
- 동일 단어가 여러 카테고리에 있어도 뜻 맞히기 보기에는 동일 철자가 중복 노출되지 않습니다.
- 빈 단어장에서도 앱이 정상 시작되며, 기본 `직접추가` 카테고리에서 바로 단어를 넣을 수 있습니다.

## 배포 전 확인

- Firebase를 사용할 때 변경된 `firestore.rules`를 Firebase Console 또는 CLI로 반드시 배포하세요. 필드 형식과 입력 길이를 제한해 손상된 데이터 및 표시 문자열 공격을 줄입니다.
- CLI를 사용할 때는 프로젝트를 지정해 `firebase deploy --only firestore:rules --project <project-id>`를 실행합니다.
- 현재 공유 단어장 모델은 익명 로그인 사용자가 단어와 카테고리를 편집할 수 있게 설계되어 있습니다. 불특정 다수에게 공개 출시하려면 교사/관리자 쓰기 권한과 서버 검증을 추가해야 합니다.
- 점수는 클라이언트가 기록하므로 공개 경쟁 랭킹으로 운영할 경우 서버 채점 또는 검증 가능한 이벤트 기록이 필요합니다.

## 기존 index.html에서 바로 고칠 핵심

### 1. 맞히면 다음 문제로 넘어가기

찾기용:

```js
setTimeout(newGame,950)
```

교체용:

```js
clearTimeout(nextTimer);
nextTimer = setTimeout(() => {
  newQuestion();
}, 650);
```

### 2. 스캔 제거

찾기용:

```html
<button class="tab" data-p="scan">📷스캔</button>
```

교체용:

```html
<!-- 스캔 탭 제거 -->
```

그리고 `scan` 섹션 전체와 `Tesseract.js` script를 제거하세요.

### 3. 한 화면 고정

찾기용:

```css
body{margin:0;
```

교체용:

```css
html, body {
  width: 100%;
  height: var(--vh);
  margin: 0;
  overflow: hidden;
  overscroll-behavior: none;
}
```

### 4. 키보드 대응

찾기용:

```js
render();newGame();
```

교체용:

```js
setupViewport();
render();
newQuestion();
```

그리고 `app.js`의 `setupViewport()` 함수를 추가하세요.
